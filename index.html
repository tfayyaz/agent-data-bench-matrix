How to read this leaderboard & scope exclusions

One component–benchmark pair counts once, even with several task configurations or citations. Task-backed benchmarks have a verified or inferred task annotation. Support-only benchmarks have an upstream runtime implementation or documented engine support, without a sampled task annotation. Verified task counts require a verified configuration whose relevant engine/tools field is not marked inferred. Verified here means inspected source, not an observed agent run.

Coverage ranks are recomputed for the selected benchmarks and evidence mode. Search and category filters retain those ranks. Counts measure representation in this curated catalogue, not speed, quality, total benchmark size or worldwide adoption. Benchmark variants count together; related named benchmarks can share datasets. Only the stated open-source distribution is in scope. Tools coverage includes clearly documented roles such as agent interface, telemetry collection, orchestration or evaluation harness; it does not mean every tool is directly called by an agent.
