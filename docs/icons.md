# Icon credits

All technology icons are **original inline SVG pictograms drawn for this repository**, implemented in `js/icons.js`. They were not downloaded from an icon library or copied from vendor logos. No external icon requests or font downloads are required.

The drawings use common metaphors: a cylinder for database engines, a snow crystal for Snowflake, a duck for DuckDB, a search/chart symbol for BigQuery, grids for tabular data, layers for table formats, books for catalogues, pages for files, and a terminal for tools. These are descriptive pictograms, not official product logos or endorsements.

Every engine, format, storage value and catalogue receives an icon, including unrecognized values through a generic fallback. Unknown values and explicit `none` have separate symbols. Visible text accompanies technology icons; decorative SVGs are hidden from assistive technology. Color is never the sole identifier.
